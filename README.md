# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

顶栏可进「试饮会」专页：审评员填会名、计划壶数、邀请审评员名单建会；受邀人各自交评后，会合页汇总每人每笔的加权分与结论。未受邀的审评员写入该会会被拒（403）；观察员能看会合页，但不能建会、不能交会内评。

这是制茶审评，不是菜谱，也不是饮食记录。

## 启动

```bash
cd projects/13-tea-blend-cupping
docker compose up --build
```

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. taster 从顶栏进试饮会专页，建会邀请 taster、计划两壶；交两笔后会合页应有两行。
5. 换 taster2（未受邀）向该会交评应失败（403）；observer 能看会合页但建会、交评均被拒（403）。
