# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

审评员还可以开**拼配试饮会**：建会时填会名、计划壶数、邀请的审评员名列表。受邀人各自交评后，会合页汇总每人的加权分与结论；未受邀人交评写入该会会被服务端拒绝（403）。观察员能看会合页，但不能建会、不能交会内评。顶栏可进试饮会专页。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏进试饮会专页；taster 建会，会名"秋拼品鉴"、计划两壶、邀请 taster。
5. taster 在会合页交两笔评，会合页出现两行（加权分、结论、审评员、壶序），第三笔因计划壶数已满被拒。
6. 换未邀请账号 taster2 尝试写入该会，返回 403"未受邀审评员不能向该试饮会交评"。
7. observer 能打开会合页看汇总，但建会、交会内评均返回 403，页面上也没有对应表单。
